# 快捷键绑定

这是 TUI 识别的每个键盘快捷键的权威目录。绑定按**上下文**分组——即它们生效的焦点或模态状态。列在"编辑器"下的绑定仅在编辑器获得焦点时生效；列在"转录区"下的绑定仅在转录区获得焦点时生效；以此类推。

全局按键组合尚不支持用户自定义——计划在未来的版本中实现（#436、#437）。Hotbar 槽位操作可通过 `[[hotbar]]` 和 `/hotbar` 配置；Hotbar 激活组合键仍为 `Alt-1` 到 `Alt-8`。

## 全局（任何上下文）

| 组合键               | 操作                                                          |
|----------------------|---------------------------------------------------------------|
| `F1` 或 `Ctrl-/`     | 切换帮助覆盖层                                                 |
| `Ctrl-K`             | 打开命令面板（斜杠命令查找器）                                  |
| `Ctrl-C`             | 取消当前轮次 / 关闭模态框 / 武装后确认退出                      |
| `Ctrl-B`             | 将受支持的前台 shell 等待移入 `/jobs`，使轮次可以继续；使用 `/jobs` 或 `exec_shell_wait` 来检查 |
| `Ctrl-D`             | 退出（仅在编辑器为空时）                                       |
| `Tab`                | 循环 TUI 模式：Plan → Act → Multitask → Operate → Plan                     |
| `Shift-Tab`          | 循环权限姿态：Ask → Auto-Review → Full Access                              |
| `Ctrl-T`             | 循环活动提供商的推理强度。DeepSeek 风格提供商循环 off → high → max → off；OpenAI Codex 循环 low → medium → high → xhigh → low。 |
| `Ctrl-Shift-T`       | 切换实时转录覆盖层（粘性尾部自动滚动）                           |
| `Ctrl-R`             | 打开恢复会话选择器                                             |
| `Ctrl-L`             | 刷新 / 清屏                                                   |
| `Ctrl-O`             | 打开所选/实时/最近工具工作的活动详情，或在编辑器为空时打开思考块的完整推理时间线 |
| `Alt-V` / `Option-V`（macOS） | 打开所选、可见或最近工具/子代理卡片的详情分页器；发出旧版 Option-V 字形的终端也会被处理 |
| `Ctrl-Shift-E` / `Cmd-Shift-E` | 切换文件树侧边栏                                        |
| `Alt-G`              | 当编辑器为空时，将转录区滚动到顶部                             |
| `Alt-1`-`Alt-8`      | 当没有模态框或内联选择器打开时，调度 Hotbar 槽位 1-8           |
| `Alt-!` / `Alt-@` / `Alt-#` / `Alt-$` / `Alt-0` | 聚焦已固定 / 任务 / 代理 / 上下文 / 自动侧边栏 |
| `Ctrl-Alt-0`         | 隐藏/显示已固定侧边栏                                          |
| `Esc`                | 关闭最顶层模态框 · 取消斜杠菜单 · 关闭 toast                   |

| `Ctrl-Enter` / `Cmd-Enter`  | 当终端支持时，强制实时操控当前轮次                       |
| `Ctrl-U`                    | 删除到行首                                               |
| `Ctrl-W`                    | 删除前一个单词                                           |
| `Ctrl-A` / `Home`           | 移动到行首                                               |
| `Ctrl-E` / `End`            | 移动到行尾                                               |
| `Ctrl-←` / `Alt-←`          | 向后移动一个单词                                         |
| `Ctrl-→` / `Alt-→`          | 向前移动一个单词                                         |
| `Ctrl-V` / `Cmd-V`          | 从剪贴板粘贴（也自动处理括号粘贴）                       |
| `Ctrl-Y`                    | 从 kill 缓冲区中拉出（粘贴）                             |

| `Ctrl-P` / `Ctrl-N`         | 循环编辑器历史记录（替代方式）                           |

| `Alt-R`                    | 搜索提示词历史记录（Alt-R 退出）                        |
| `Tab`                       | 斜杠命令 / `@` 提及补全（弹出感知）                     |
| `Ctrl-O`                    | 在编辑器获得焦点时，打开外部编辑器编辑草稿               |
| `! command`                 | 通过正常的审批、沙箱和输出界面运行 shell 命令             |

### Hotbar

Hotbar 触发语义被有意限制为仅 `Alt-1` 到 `Alt-8`。在 macOS 键盘上，这是 Option/Alt 键加数字行。裸 `1`-`8` 在编辑器中被视为普通文本输入，并仍由选择器、onboarding、审批提示和模态视图所有。

功能键和 `Cmd-1` 到 `Cmd-8` 不是主要的 Hotbar 组合键。许多终端将这些键保留给标签页、窗口或操作系统快捷键，有些从不将它们转发给终端应用。如果终端被配置为发送 `Alt-1` 作为自定义快捷键，Hotbar 会收到相同的可靠组合键。

全新配置解析为以下默认栏，除非 `[[hotbar]]` 覆盖它或 `hotbar = []` 禁用它：

| 槽位 | 组合键  | 默认操作            | 标签       |
|------|---------|--------------------|-----------|
| 1    | `Alt-1` | `voice.toggle`     | `voice`   |
| 2    | `Alt-2` | `session.compact`  | `compact` |
| 3    | `Alt-3` | `mode.plan`        | `plan`    |
| 4    | `Alt-4` | `mode.agent`       | `agent`   |
| 5    | `Alt-5` | `mode.operate`     | `operate` |
| 6    | `Alt-6` | `palette.open`     | `palette` |
| 7    | `Alt-7` | `sidebar.toggle`   | `side`    |
| 8    | `Alt-8` | `trust.toggle`     | `trust`   |

| 焦点状态 | Hotbar 行为 |
|-------------|-----------------|
| 编辑器为空、有文本或空白字符 | `Alt-1`-`Alt-8` 调度已配置的槽位 |
| 侧边栏聚焦、隐藏或自动 | `Alt-1`-`Alt-8` 仍调度已配置的槽位 |
| 斜杠菜单或历史搜索打开 | 被阻止；内联选择器拥有按键事件 |
| 命令面板、帮助、审批、文件选择器、会话选择器、Fleet 设置或任何模态栈 | 被阻止；模态框拥有按键事件 |
| Onboarding | 被阻止；onboarding 拥有数字选择 |

### `@` 提及

输入 `@<部分>` 打开文件提及弹出框。`↑`/`↓` 循环条目，`Tab` 或 `Enter` 接受。`Esc` 隐藏弹出框。从 v0.8.10 (#441) 开始，补全根据提及频率重新排序——你经常且最近提及的文件会排在最前面。

### `#` 快速添加（记忆）

当 `[memory] enabled = true` 时，输入 `# foo` 并按 `Enter` 会将 `foo` 作为带时间戳的要点附加到你的记忆文件中，**而不**发送轮次。参见 `docs/MEMORY.md`。

## v0.8.29 审计记录

- **`Shift+Enter` / `Alt+Enter` 换行现在在 Windows 上的 VSCode 中正常工作 (#1359)。** crossterm 的 `PushKeyboardEnhancementFlags` 命令在 Windows 上无条件返回 `Unsupported`（`is_ansi_code_supported() == false`），因此 Kitty 键盘协议转义序列从未写入终端。没有它，VSCode 的 xterm.js 保持旧版模式，其中 `Shift+Enter` 与普通 `Enter` 无法区分，导致编辑器发送消息而非插入换行。修复方案是直接在 Windows 上写入 push/pop 转义序列（`\x1b[>1u` / `\x1b[<1u`），绕过 crossterm 的能力门控。VSCode 集成终端和 Windows Terminal ≥1.17 都支持 Kitty 键盘协议；不理解这些序列的终端会静默丢弃它们。

## v0.8.13 审计记录

- **Ctrl-S 是暂存，不是历史搜索。** 在此版本中修复 — `Alt-R` 是历史搜索。
- **幽灵 `Alt+Up` 已移除。** "编辑最后排队的消息"绑定在 README 中列出，但在按键分发代码中从未存在。
- **v0.8.13 中编辑器为空时裸 Up/Down 箭头滚动转录区。** 此前 `should_scroll_with_arrows` 门控被硬编码为 false，意味着即使编辑器为空，裸箭头也始终导航编辑器历史记录。虚拟终端（Ghostty、Codex、Kitty-protocol）用户尤其受影响，因为他们无法使用 Cmd+Up / Alt+Up 快捷键。
- **可配置快捷键映射 (#436) 和 `tui.toml` (#437) 仍被推迟。** `TuiPrefs` 结构体和加载器存在于 `settings.rs` 中，但未在启动时连接。允许 `~/.codewhale/tui.toml` 覆盖单个条目的命名绑定注册表仍在待办中。
- **未发现其他损坏的绑定。** 上面列出的所有其他组合键都解析为 `crates/tui/src/tui/ui.rs`（按键事件分发）或 `crates/tui/src/tui/app.rs`（模式 + 状态转换）中的实时处理程序。
