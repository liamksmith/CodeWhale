## 如何添加语言区域

1. 将区域代码添加到 `web/lib/i18n/config.ts` 中的 `locales` 数组。
2. 将标签添加到 `web/components/locale-switcher.tsx` 中的 `LOCALE_LABELS`。
3. 在 `web/lib/i18n/dictionaries/<code>/` 下搭建翻译词典。
4. 添加区域路由段——一旦 `locales` 数组包含该代码，Next.js `[locale]` 将自动拾取。
5. 更新此矩阵。
