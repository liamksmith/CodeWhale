## 剩余差距

- 当用户报告连续两次请求的命中率低时，仍需要请求体快照夹具来进行首个差异字节诊断。
- 仍需要基准测试框架夹具来支持 #2956 风格的重复转录增长和大工具输出回放。
- 每个已完成任务的成本和配额式遥测仍在此切片之外；它们属于 provider 用量/定价显示工作。
